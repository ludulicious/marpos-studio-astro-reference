Your website deserves attention between launches. A new story, an updated introduction, or a clearer image caption should be easy to write and straightforward to check.

Marpos Studio brings your content into a desktop workspace. Edit the story, fill in the page details, and preview the result in your actual website before deciding what to keep.

## Your content, in your repository

Astro collections describe the content. Your website decides how it looks. Studio helps you work with those same files, without introducing a second content database.

- **Write comfortably.** Move between visual editing and Markdown source.
- **Check the real page.** Preview changes using the website’s own templates.
- **Review deliberately.** Keep a local draft or review a connected GitHub website before publishing.

Start with [your first content edit](/blog/your-first-edit/) or read [about this website](/about/).
