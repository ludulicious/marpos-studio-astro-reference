A useful first edit is small enough to check carefully. Choose a story you know well and improve its introduction or summary.

## Begin with the page details

Open the journal collection and select a story. The title and description help readers decide whether the page answers their question. Keep both specific, and check that the description makes sense on its own in a list of articles.

## Write the story

Use the visual editor for paragraphs, headings, lists, and links. Switch to source when you need to inspect the Markdown directly. Both views edit the same document.

> A good first session ends with one change you understand and a preview you have actually read.

1. Change the opening paragraph.
2. Open **Preview this page**.
3. Read the sentence in the context of the website.
4. Choose **Save changes** when you want to keep it locally.

Saving locally does not deploy the website. For a local repository, use your usual Git workflow when the change is ready to share.

## Before you move on

- [ ] The introduction tells readers what they will learn.
- [ ] The description works in the journal list.
- [ ] Links lead to the intended pages.
- [ ] The saved preview matches the change.
