An image can set a mood or explain something a paragraph cannot. Its description helps the same content reach readers who do not see the image.

## Choose the image and the words together

The hero field in this website contains a local image path and alternative text. Both are saved in the story’s frontmatter and used by the Astro template.

Describe what is relevant to this page. For a screenshot, that might be the selected content collection or the relationship between editing and preview. Avoid repeating a nearby heading.

## Use the media workflow

Select an existing image or upload a supported image into the website’s public media folder. The reference uses `/images/` paths, so the same file works in lists, individual stories, and local previews.

- Keep the file name meaningful.
- Check the crop in the story and the journal list.
- Read the alternative text without looking at the image.
- Confirm the image still works after saving and reopening the page.

The pictures in this reference are abstract assets from the official starter. Replace one with your own image when testing a real editorial update.
