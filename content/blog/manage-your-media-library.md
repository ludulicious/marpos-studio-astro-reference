## Before you start

Open the [media library](/library/). The reference includes 24 CC0 photographs and three CMS tutorial videos. Photographs live in the repository; videos play from their original YouTube provider.

## Find the right asset

1. Search for a subject, title, or photographer. Try **forest**, **desk**, or **stone**.
2. Choose a collection to narrow the results to Workspaces, Nature, Architecture, or CMS tutorials.
3. Open an asset to see its full preview, image description, creator, source, and license.
4. Use **Reset** to clear both filters. Search and collection choices are retained in the URL, so you can bookmark a useful view.

## Use a photo in a chapter

1. On a photo detail page, choose **Copy image path**, or select the displayed local path.
2. In Marpos Studio, open a chapter in **Blog** and find its **hero** details.
3. Put the path in **src** and write context-specific **alt** text. You can also select the existing local file through Studio’s media workflow.
4. Save the edit and open **Preview this page**. Check the crop on the chapter and the manual list.

For example, `/images/library/light-through-the-trees.jpg` points to a real local photograph. These paths stay relative to the website’s public folder; do not add the GitHub Pages repository prefix to content fields.

## Keep a record of the source

The photo detail page links to the photographer, original directory entry, and CC0 license. CC0 does not require attribution, but preserving those records makes later editorial checks easier. Video lessons retain their original publisher and source lesson links. They are embedded from YouTube without redistributing the video files.

**Check your result:** save and reopen the chapter. The chosen image should still appear, and its description should make sense without seeing the photograph.

Continue with [image descriptions](/blog/write-accessible-image-details/) or [adding a video lesson](/blog/add-video-to-a-guide/).

## Use Studio’s built-in media pickers

The repository also configures native **Photos** and **Videos** libraries in Marpos Studio. Open **Photos** to edit image details, categories, credits, visibility, or order. Open **Videos** to manage the linked YouTube lessons.

In a chapter’s story editor, use **Choose image** or **Choose video** to insert an existing library entry. These pickers use the same underlying records as the website gallery. Hiding a library item removes it from the public gallery while allowing existing stories to keep using it.
